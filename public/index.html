내 PC에서 Codex 구독 연결하기
  1. 온계획 프로젝트와 Node.js, Codex CLI를 준비합니다.

  3. 프로젝트 폴더에서 npm run dev:ai를 실행하고 표시된 로컬 주소를 엽니다.
  4. 아래 ‘연결 다시 확인’을 누른 뒤 계산 결과에서 AI 설명을 요청합니다.
