# 가상 고객 v1과 기초 진단

사용자가 선택한 유형은 **40대 주택보유 맞벌이 부부와 초등자녀 1명**이다. 아래 금액·직업·선호는 분석을 위한 합성 입력이다. 실제 면담·계약서·계좌명세서에서 얻은 사실도, 통계가 관측한 대표가구도 아니다. [상세 입력](../research/customer/customer-input-v1.json)과 [설정 근거](../research/customer/setting-basis.json)를 구분하여 보관한다.

## 입력 버전

`candidate-1-v1.0`, 기준일 2026-11-16, 첫 계산월 2026-12. 부부는 43세·41세 민간 근로자, 자녀는 11세 초등학교 5학년으로 설정했다. 실거주 주택 유지, 매각·갈아타기·사업소득 제외가 범위다. 유형 선택이 모든 금액과 선호에 대한 참가자의 최종 승인이라는 뜻은 아니다.

| 항목 | 합성 입력 |
|---|---:|
| 자산 합계 / 주택 | 6억 8,500만원 / 5억 5,000만원 |
| 현금·예금 / 일반 투자계좌 | 3,000만원 / 2,000만원 |
| 연금저축펀드·IRP·DC 합계 / 차량 | 7,500만원 / 1,000만원 |
| 주택담보대출 | 2억 2,000만원, 연 명목 4.8%, 잔여 300개월, 월말 원리금균등 |
| 세후 월소득 / 월평균 생활비 | 650만원 / 350만원 |
| 현재 저축·투자 이체 | 월 130만원 |
| 대학 준비 | 기존 예금 중 2,000만원 배정 + 월 30만원, 2034-02까지 희망 6,000만원·최소 4,000만원 |
| 은퇴 | 각자 60세 희망, 부부 월생활비 300만원의 2026년 구매력 기준; 연금 예상액 미확정 |

대학 목표는 미래 명목금액이다. 은퇴 생활비는 현재 구매력 기준이다. 연금 잔액은 기준안에서 중도인출하지 않으며 법적으로 절대 인출할 수 없다는 뜻은 아니다. 예금 만기·중도해지 이자와 투자계좌의 손실·비용·결제시차도 현금과 구분해야 한다.

## 공식 통계는 규모 참고다

[2025 가계금융복지조사](https://mods.go.kr/boardDownload.es?bid=215&list_no=439535&seq=1)의 40대 가구주 평균 자산은 62,714만원, 자산 중앙값은 39,990만원이다(인쇄 44쪽). 자산·부채는 2025-03-31, 소득은 2024년 연간 기준이다. 40대 평균 총부채는 무부채 가구를 포함하고, 연총소득은 세후 급여가 아니다. DC를 포함한 이 재무제표와 통계의 범위가 같다고 전제해 배수나 분위 순위를 계산하지 않는다.

[2025 사교육비 조사](https://www.mods.go.kr/board.es?act=view&bid=245&list_no=443953&mainXml=Y&mid=a10301010000)의 초등 참여학생 월평균 51.2만원은 지출 수준 참고다. 고객의 교육비 65만원은 사교육 55만원과 방과후·교재 등 10만원을 합한 별도 가정이며 평균을 적정 지출로 권고한 것이 아니다. 취업자 2인·가구원 3인·40대·자가 통계를 조합해 관측된 “맞벌이 초등자녀 가구”라고 부르지 않는다. [통계 정의와 위치](../research/customer/statistics.json)를 참고한다.

## 실제 기초 계산

[결과 JSON](../research/customer/baseline-results.json)은 8개 확인 항목 통과를 기록한다. 아래는 연구용 Python 결과이며 웹 실행 완료의 증거가 아니다.

- 순자산은 **4억 6,500만원**, 주택 비중은 자산의 약 **80.29%**다. 큰 순자산과 현금 여유를 동일시하지 않는다.
- 월 상환액은 약 **126.06만원**이다. 생활비·상환 후 저축 가능액 약 **173.94만원**, 현재 이체 후 미배정 잉여는 약 **43.94만원**이다.
- 상환액/세후소득 약 **19.39%**는 이 예산의 지표이며 법정 DSR이 아니다.
- 동일 금리를 유지하면 204번째 납입 후 대출잔액은 약 **1억 32.64만원**이다. 생일 당일 잔액이나 미래 금리 예측으로 부르지 않는다.
- 대학자금은 무수익 기준 87회 적립 후 **4,610만원**, 희망액 대비 **1,390만원 부족**이다. 이는 단순 산술 기준이며 실패확률·수익률 전망이 아니다.

## 소득중단 스트레스와 수정

A의 소득이 6개월 중단되고 남은 월소득 270만원, 조정한 생활비 305만원, 정상 대출납입을 유지한다고 가정했다. 저축·투자 납입은 중단하고 실업급여·퇴직금·투자매각은 넣지 않았다. 월평균 부족은 약 161.06만원, 6개월 합계 약 **966.36만원**이다. 교육배정 원금 외 현금성 원금 1,000만원에서는 약 **33.64만원**이 남는다.

이를 현재 유동성 위기나 충분한 비상자금의 증명으로 쓰지 않는다. 예금 접근 가정과 월평균화에 의존하며 실제 지급일 유동성을 확인하지 않았다.

초기 해석은 “교육자금 보존”의 범위를 넓게 읽을 여지가 있었다. 기존 배정 원금만 보존되고 교육저축 6회, **180만원**은 중단된다. 보충하지 않으면 대학자금 산술값도 **4,430만원**으로 줄어든다고 수정했다. 중단 저축을 스트레스 생활비에 다시 더하지 않았다. [실제 검토·수정 기록](../research/customer/review-log.json).

## 웹 예제에 추가된 가정과 결과

[수동 가져오기 예제](../examples/contest-customer.json)는 기본 빈폼과 분리되어 있다. 현재 웹에는 추가 월예산 40만원, 교육배정 외 현금 하한 500만원, 최초 12개월 동안 선형 감소하는 가상 추가상환 수수료율 0.5%를 명시했다. 실제 금융계약에서 확인한 값이 아니며 기존 고객 v1의 미확인 계약조건을 소급해 확정한 것도 아니다. [매핑과 추가 가정](../fixtures/provenance.json).

웹의 현금 하한 회복 정책에서는 소득이 돌아온 뒤에도 교육저축 일부가 제한된다. 따라서 목표월 교육배정은 약 **4,356.64만원**이다. 하한을 0으로 두어 6개월 중단만 반영한 **4,430만원**과 구분한다. [독립 검산](../fixtures/verification-results.json)은 두 경우를 각각 확인했다. 현금 유지안은 기준안과 같으며 교육 목적 배정만으로 순자산을 늘리지 않는다.

노후 충족률, 보험 충분성, 최적 비상자금, 투자 권고는 아직 결론 내리지 않는다. 가입이력·예상연금, 보장내용, 실제 대출 수수료·재산정일, 비정기지출 일정과 최종 목표 선호의 확인이 필요하다.
