# 실제 검증 이력과 한계

검증은 계산 도구가 명시한 입력에서 올바르게 동작하는지 확인한 것이다. 고객 적합성, 법규 전체, 장기 투자성과, 웹 UX, 실시간 AI의 정확성은 각각 별도의 검증이다. 아래 수를 합쳐 “총 테스트 수”나 제품 전체 정확도로 발표하지 않는다. 그룹·개별 검사·무작위 시도·연결 결과 행은 단위가 다르다.

| 대상 | 기록된 결과 | 무엇을 확인했는가 |

고객의 8개 항목에는 고정 합성 입력의 회귀 확인도 포함된다. 임의의 새 고객 입력과 날짜·세제·계좌를 모두 검증했다는 뜻은 아니다. 연구 결과 파일을 웹 테스트 결과로 복사해 부르지 않는다.

## 이번 JavaScript 웹 코어와 서버

[웹 독립 결과](../fixtures/verification-results.json)는 Node 24.22.1·Python 3.12.14에서 코어 JS **18개 테스트**, Python **24개 확인**, 독립 원장식 **88,992개 대조**의 통과를 기록한다. 원장 최대 차이는 약 3.19×10⁻⁷원이며 지정 입력·허용오차 안의 결과다. Python 확인에는 Node 시험 성공도 포함되므로 수를 합산하지 않는다.

이후 서버 시험 **18개**(그 안에 HTTP 하위시험 6개 포함)와 [로컬 AI 브리지 시험](../tests/ai-bridge.test.mjs) **14개**가 추가되어 JS 자동시험 합계는 **50개**다. 브리지 시험은 모의 CLI 실행을 사용하며 실제 모델 호출 14건을 뜻하지 않는다. [통합 검증 기록](../artifacts/verification.json)은 이 구분과 로컬 브라우저 확인을 함께 보존한다. 빈폼, 가상 파일 가져오기, 정상/스트레스 수치, 변경 후 재계산, 내보내기, 초기화, 0원 고객, 390px 폭을 수동 확인했으며 교차 브라우저·보조기술 전체 감사는 아니다.

추가상환 예산의 수수료 포함, 기존 교육배정의 비상 사용, 미지급 의무와 연체 원금의 분리, 현금 하한 회복 후 교육납입 공백을 확인했다. 6개월 중단만 반영한 교육자금 4,430만원과 현금 하한 회복까지 반영한 약 4,356.64만원을 별도 시험했다. 실시간 AI 호출과 배포 후 검수는 이 통과 수에 포함되지 않는다.

## 실제 구독 AI 호출

[실호출 증거](../artifacts/live-ai-verification.json)는 2026-11-16 07:20:46 UTC의 합성 고객 **1건**을 기록한다. 인증은 `chatgpt`, 공급 경로는 `codex_subscription`, 응답 시간은 **29.823초**다. 5개 설명의 숫자와 근거 ID를 검증했고 월 상환액 1,260,593원, 추가상환/현금안 대출잔액 138,982,748/180,489,703원, 수수료 12,955원, 이자차이에서 수수료를 뺀 6,706,954원, 스트레스 교육배정 43,566,398원·최저 비배정예금 336,440원을 원장과 대조했다. 교육배정이 순자산을 늘리지 않는다는 설명과 최적·안전 보장을 하지 않는 해석도 검토했다.

이후 브라우저 AI 버튼으로 두 번째 실제 생성을 요청해 5개 설명과 수치 근거 표시를 확인했다. 수동 전달 요약은 7,910자로 복사되었고 재무 입력 27개·대안 3개를 포함하며 개인 계획명은 제외됐다. [통합 기록](../artifacts/verification.json)의 실제 생성 성공 수는 **2건**, 수정 전 중단된 시작 시도는 **3건**이다. 중단 시도를 성공 응답이나 정상 테스트 통과로 세지 않는다.

실제 모델 ID는 CLI 이벤트에 없어 “Codex CLI 기본 모델”이라고 기록했다. 자동 숫자 검사는 모든 의미·누락·재무적 적합성을 증명하지 않는다. 단일 합성 고객의 성공을 일반 정확도나 계정 과금 감사로 확대하지 않는다.

## 실제 발견한 문제

- **PyPortfolioOpt 설치와 import의 차이:** 패키지 설치와 `pip check`는 통과했지만 의존 경로의 `packaging` 부재로 import가 실패했다. 격리 환경에 `packaging==26.3`을 추가하고 lock을 갱신한 뒤 재실행했다.
- **HARK 의존성 누락:** `sympy` import가 실패했다. `sympy==1.14.0` 추가 후 검증이 통과했으며 원본 HARK 소스는 수정하지 않았다. `pip check`만으로 실행 가능성을 확인할 수 없었다.
- **원장 연체 상태:** 최초 코드는 미납 원금을 결과 로그에만 남겨 다음 기간 선택 투자를 막지 못했다. 기존 부채의 부분집합으로 이월하고, 연체 동안 선택 지출을 제한하며 해소 시 중복 상환하지 않도록 수정했다.
- **입력 경계:** NaN 우선순위, 빈 목표 ID, 중복 ID 등을 거부하도록 보완했다. 이미 현금 하한보다 부족한 시작 상태는 별도 부족 지표로 표시했다.
- **고객 스트레스 해석:** 교육배정 원금 보존과 미래 적립 중단을 분리해 180만원의 납입 공백을 추가 표시했다. 입력을 유리하게 바꾼 수정이 아니다.
- **로컬 CLI 시작 안내의 오분류:** 의도적으로 끈 Code Mode의 알려진 시작 안내를 금지 도구 실행으로 오분류했다. 정확히 일치하는 그 안내만 예외 처리했다. 실제 도구 실행과 다른 오류의 차단은 유지했으며 브리지 회귀시험과 실제 호출로 재확인했다.

공개 다운로드의 네트워크 차단은 실행 환경 문제였으며 라이브러리 버전의 부재로 판단하지 않았다. 소스 수집 보조 스크립트의 문법오류는 AI 작성 코드의 문제로 구분했다.

## 검증이 드러낸 한계

CVaR의 분수 꼬리질량 예제에서 정확한 값은 8.285714%, 단순 꼬리평균은 7%였다. 목표수익률 제약에서 두 최적화 구현의 목적값 차이는 약 6.21×10⁻¹¹이었다. 같은 학습 표본의 위험 감소에는 평균수익률 감소도 동반되었고, 다른 합성 분포에서는 위험 비교가 역전됐다. 역사적 백테스트나 미래 우위의 증거가 아니다.

연결 예제의 공동 목표 달성 비율은 두 정책 모두 4/7이었다. 평균 부족액은 달랐지만 시험 단위를 원화·만원이나 고객 예상성과로 번역하지 않는다.

HARK는 결정론 해와 약 1.78×10⁻¹⁵의 최대오차를 보였고, 확률소득의 자산격자를 세밀하게 할수록 비교 오차가 줄었다. 같은 이산 소득분포를 사용했으므로 연속분포의 근사오차까지 검증한 것은 아니다. 장기 생애·한국 세금/연금·위험자산 모형과 전체 upstream 테스트는 미검증이다.
