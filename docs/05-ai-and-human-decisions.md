# AI 활용과 사람의 결정 기록

개발 과정에 AI를 사용한 사실과 웹앱이 실시간 모델을 호출하는 기능은 다르다. 이 프로젝트의 자료조사·설계·코드·검토·문서 작성에는 AI를 사용했다. 실시간 AI 연결과 그 응답 검증은 [웹 상태](06-web-architecture.md) 및 [배포 기록](07-deployment-runbook.md)에 실제 완료한 범위만 적는다.

현재 호스팅 Worker에는 모델을 연결하지 않는다. 사용자가 별도 API 비용을 원하지 않는다고 밝혀, 이미 설치된 Codex CLI의 ChatGPT 로그인을 사용하는 **로컬 연결**로 방향을 정해 구현했다. [실제 구독 AI 1건](../artifacts/live-ai-verification.json)은 29.823초에 5개 설명을 반환했고 수치·근거 연결과 핵심 해석을 검토했다. 실제 모델 ID는 제공되지 않아 “Codex CLI 기본 모델”로 표시한다. [계산 검증](../artifacts/verification.json)과 모의 브리지 시험 14개는 이 실호출과 별도 증거다. 기본 계산해설은 규칙 기반이다. [구독 AI의 실행 경계와 공식 근거](08-subscription-ai.md).

## 네 가지 기록을 분리한다

| 종류 | 기록 방법 |
|---|---|
| 사용자 요청·결정 | 실제 발화 또는 명시적으로 표시한 요약. 고객 유형 선택과 금액 승인 등을 구분 |
| 검색 질의·AI 작업지시 | 도구명·질의/프롬프트·시각·범위. 하위 에이전트 지시를 사용자 발화로 바꾸지 않음 |
| AI 제안·설명 | 출처·가정·수치가 있는 제안. 참가자가 채택했다고 자동 처리하지 않음 |
| 실행·검증 증거 | 코드 버전, 입력 해시, 결과 파일, 실패·수정·재실행과 한계 |

실제 검색 질의 예시는 다음과 같다. [통계 조사 기록](../research/customer/statistics.json)에 도구·목적·횟수 정의가 남아 있다.

> 2025년 가계금융복지조사 결과 40대 자산 부채 소득 통계청

이는 원문 검색 질의이며 참가자의 상담 내용이나 판단문이 아니다. 공개 문서의 나머지 회고 문장은 과정 요약이다. 모든 원래 대화를 전사했다고 주장하지 않는다.

## 이번 과정의 결정과 교정

| 구분 | 확인된 내용 |
|---|---|
| 사용자 교정 | 자료·코드를 먼저 평가하고 통합 구조 뒤에 고객을 선정하도록 순서를 변경 |
| AI 수정 | 초기 은퇴 고객 우선권을 철회하고 여러 유형의 구조 적합성을 다시 비교 |
| 사용자 선택 | 40대 주택보유 맞벌이 부부와 초등자녀 1명 유형 선택 |
| AI가 작성한 가정 | 고객 v1의 금액·직업·목표와 선호. 통계값이나 실제 인터뷰가 아니며 유형 선택만으로 세부 승인 완료라고 쓰지 않음 |
| 사용자 제품 요구 | 빈 입력폼을 통한 새 가계 작성, 웹 도구 실제 활용, 코드와 문서의 분리 |
| 사용자 비용 요구 | 별도 API 비용 대신 설치된 ChatGPT/Claude 구독 활용 요청. 설치·로그인을 확인한 Codex의 로컬 실행 경로를 채택 |
| 코드·해석 교정 | 연체 원금 이월, 비유한 입력 거부, 교육저축 중단의 목표 영향 반영 |

[고객 검토 로그](../research/customer/review-log.json)는 검토 요약이며 참가자의 최종 승인서가 아니다. 참가자 본인이 확인하지 않은 “나는 이 대안을 선택했다”, 상담 경험·빈도·성과·실제 고객 동의 문장을 대필하여 사실로 제출하지 않는다.

## 실행 시 AI의 역할

AI가 맡을 수 있는 것은 누락·모순 질문, 계산 도구가 반환한 결과의 설명, 검증한 출처 연결, 대안의 반대근거다. 핵심 금액은 고정 계산 코드가 산출한다.

AI는 입력을 조용히 바꾸거나, 법·세금·연금 규칙을 만들어 넣거나, 계산하지 않은 성공확률과 최적 투자비중을 제시해서는 안 된다. 결과의 값·단위·기간·입력 버전이 설명과 일치하는지 검증한다. 필수 입력 미확정, 지원하지 않는 규칙, 낡은 결과를 정상 완료로 설명하지 않게 한다.

정해진 템플릿 설명은 “규칙 기반 설명”, 저장된 과거 응답은 “저장된 예시”, 실제 모델 호출만 “실시간 AI”로 표시한다. 외부 모델이 실패해도 기본 계산은 작동하도록 설계하되, 실제 장애 시험을 통과했는지는 따로 기록한다.

로컬 AI는 사용자가 명시적으로 요청할 때 같은 입력을 재계산하고 그 결과를 Codex CLI에 전달한다. 호스팅 화면에서는 요약 미리보기·복사·TXT 내보내기로 사용자가 ChatGPT/Claude에 직접 전달한다. 수동 전달 자료 자체를 AI 답변이나 검증된 조언으로 부르지 않는다. 자동 API 전환·크레딧 추가 구매·인증파일 복사는 구현 범위에서 제외한다. 구독 이용량이나 이미 사용 가능한 크레딧의 소모까지 없다고 단정하지 않는다.

첫 실호출 검토에서는 상환·현금·교육배정의 교환관계, 현금하한과 의무미납의 구분, 모형 한계와 특정 대안의 최적성 비보장을 확인했다. 이후 브라우저에서 두 번째 실제 생성과 설명 5개·근거 표시를 확인했고 수동 요약 복사도 검수했다. 수정 전 시작 중단 3회는 성공 2건과 구분한다. 한 합성 고객의 성공을 모든 고객·미래 응답의 정확성으로 확대하지 않으며 계정 청구 화면은 별도 감사하지 않았다.

## 대회 부록으로 옮길 때

[공식 양식](https://www.ifpk.org/download?attach_file_usn=11074&data_usn=181809)에 따라 실제 도구·버전·핵심 프롬프트, AI 결과, 참가자가 채택·수정·기각한 이유, 검증과 본문 반영을 연결한다. 오류를 찾지 못했다면 검증방법과 그 사실을 적는다. 존재하지 않은 실패 사례를 증거로 만들지 않는다.

공개 저장소에는 개인정보·개인 대화 원문·키·계정정보를 넣지 않는다. 공개를 위해 원문을 생략한 구역은 요약임을 표시하며, 필요한 원본 증거는 비공개 제출 자료로 별도 관리한다. 이 공개 문서만으로 참가자 식별정보나 동의서가 준비되었다고 보지 않는다.
